# CRUD Categorias e Produtos

Projeto desenvolvido para prática de API REST utilizando:

- Node.js
- Express
- MySQL
- Knex
- HTML
- Bootstrap
- JavaScript

## Funcionalidades

- CRUD de Categorias
- CRUD de Produtos
- Relacionamento Produto x Categoria

## Banco de Dados

Executar o script:

database/create_database.sql

O script irá:

- Criar o banco loja_26_1
- Criar a tabela categoria
- Criar a tabela produto
- Inserir dados iniciais para testes
